**Liberty Immortal 0.8 beta**: GTA IV on Android, tuned for a steady 30 FPS on Immortalis GPUs.

Signed with the same key as every earlier Mali / Immortal-Fix build, so it installs over them as an update.
Built for ARMv9 (Dimensity 8400 and newer).

### What this beta brings
- **Locked 30 FPS** with the screen refresh rate matched to the frame limit, a tuned profile for Mali-G1 /
  Immortalis class chips, and a heat guard that trims a draw budget (small shadow casters) instead of the draw
  distance when the phone gets hot.
- **Farther world**: draw distance 0.8 with a floor of 0.9, a calm shadow draw budget and no flicker.
- **Less memory and bandwidth**: ASTC textures for DXT1, DXT3/DXT5 with simple alpha (least squares fit) and DXN
  normal maps.
- **Touch controls**: swipe camera that turns faster while moving, steering where the newest finger wins and
  builds up gradually, drive-by that ignores brushes, map screen stick, zoom and legend buttons, ghost touch
  rejection at the screen edge.
- **Cheats**: instant base game and episode cheats; the four Gay Tony cheats dial once and are instant afterwards
  (`liberty_cheat_ids.txt`).
- **Debug logs** (Play (Debug Log), copied to Downloads/LibertyRecomp): frame times, thread load, a CPU sampler
  (`cpu-thread:` / `cpu-hot:`), texture and shadow statistics, finger events.

### Known issues
- Beta: expect rough edges and save often.
- Long sessions still heat the phone up (it throttles at thermal status 3); the CPU sampler in the debug log is how
  that gets measured and reduced.
- Details of every setting: `docs/android/IMMORTAL_FIX.md`.
